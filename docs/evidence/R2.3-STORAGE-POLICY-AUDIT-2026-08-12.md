## 7. Desenho R2A (menor correção — proposta)

### Resolve
- `public=true` → `false`
- SELECT público (`boletos_read_all`)

### Não resolve (fora de escopo)
- tenant / condominium_id / site_id / memberships / ownership fino

### Passos
1. `DROP POLICY "boletos_read_all"`
2. `CREATE POLICY "boletos_select_authenticated"` — SELECT TO authenticated, USING `bucket_id = 'boletos'`
3. `UPDATE storage.buckets SET public = false WHERE id = 'boletos'`
4. **Manter** insert/update authenticated (sem apertar ownership nesta R2A)

### SQL proposto (NÃO EXECUTAR)

```sql
-- R2A PROPOSTA — fechar exposição pública do Storage boletos
-- Project: zaemlxjwhzrfmowbckmk
-- NÃO executar sem autorização explícita

BEGIN;

DROP POLICY IF EXISTS "boletos_read_all" ON storage.objects;

DROP POLICY IF EXISTS "boletos_select_authenticated" ON storage.objects;
```
