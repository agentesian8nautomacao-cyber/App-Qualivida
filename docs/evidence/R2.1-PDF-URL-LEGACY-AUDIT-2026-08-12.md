### Classificação: **LOW**

**Motivo:** com **0 boletos** e **0 `pdf_url`**, tornar o bucket privado e remover `boletos_read_all` **não quebra downloads de linhas existentes** por fallback de URL. O fluxo canônico (`.download()` + path) continua sendo o alvo, com policy SELECT authenticated (proposta R2).

**Ressalvas (não elevam para HIGH com dados atuais):**

- Código **ainda** tem fallback `pdfUrl` — se no futuro forem inseridos `pdf_url` públicos, quebrarão.
- Possíveis **arquivos órfãos** no bucket (Fase 0) não ligados a rows: impacto de dados/arquivo, não de UI de lista vazia.
- Inventário de objetos Storage não revalidado agora.
